# g4 — 세븐 원더스 듀얼 lint 정리

> **정정 (PL, 2026-09-16)**: 최초 발급 시 `no-alert` 1건이 이 파일에 있다고 적었으나 **오지정**이었다.
> 실제 위치는 `app/pages/games/rich/index.vue:237`(`g1` 소유)이며, PL이 grep 출력의 파일 헤더를
> 한 줄 밀려 읽은 것이 원인이다. 담당 개발자가 저장소 전체 grep 으로 확인해 반려했다.
> → `no-alert` 항목은 `g1` 계약서 C4 로 이관. 이 계약서는 lint 정리만 남긴다.
> C1·C2 는 취소, C3·C4 만 유효.

## 목적

`g4` 소유 파일의 lint 위반을 없앤다.

## 작업범위 (이 파일만)

- `app/pages/games/seven-wonders-duel/index.vue`

## 계약

- C1. 237행 부근 네이티브 `confirm()` 제거 → **Element Plus `ElMessageBox.confirm`** 으로 교체.
  이 저장소는 `@element-plus/nuxt` 를 쓰므로 auto-import 된다. 문구는 한국어, 기존 확인 문구 유지.
  취소 시 기존 `confirm` 취소와 **동일하게 아무 일도 일어나지 않아야 한다**(`ElMessageBox`는 reject
  하므로 `.catch(() => {})` 또는 try/catch 로 받아 조용히 무시 — 에러가 콘솔로 새지 않게).
- C2. `confirm`이 동기였던 자리를 async 로 바꾸면서 **분기 로직이 뒤집히지 않았는지** 직접 확인한다.
- C3. lint 위반 제거: `pnpm exec eslint --fix <파일>` 먼저, 남은 건 수동.
- C4. 점수 계산 로직은 손대지 않는다.

## 제외범위

- 다른 lane 파일 전부. 화면 디자인 변경·새 기능.
- `pnpm generate` 실행 금지(`.output/` 충돌).
