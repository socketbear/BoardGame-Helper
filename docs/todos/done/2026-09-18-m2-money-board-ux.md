> **통합 정정 (PL)**: sm 이상에서 칸이 18rem 고정이라 오른쪽에 여백이 몰려서 `sm:justify-center` 를 추가했다.

## 계약

### 네모 크기·반응형

- C1. 보드는 CSS grid. **모바일(360px 포함)에서도 최소 2열.** 넓어지면 열이 늘어난다.
  네모 한 칸 **최대 폭 18rem**. 예: 기본 `grid-cols-2`, `sm` 이상 `repeat(auto-fill, minmax(12rem, 18rem))` 류.
  정확한 값은 판단하되 360px·768px·1280px 세 폭에서 어떻게 나오는지 보고에 적는다.
- C2. 네모는 칸 폭을 채우고(`w-full`), 높이는 비율로(`aspect-square` 또는 `aspect-[4/3]` 중 판단).
  고정 `h-32 w-32` 제거. 겉모습 규칙(테두리 색·회색은 흰 글자·`border-4 rounded-lg`)은 유지.
- C3. **글자 크기**: 이름은 칸 크기에 맞게 크게(예: `text-base sm:text-xl`, 굵게, 한 줄 말줄임),
  잔액은 더 크게(예: `text-2xl sm:text-4xl`, 굵게, `tabular-nums`). 360px 2열에서 7자리 금액(1,000,000)이
  **넘치지 않아야** 한다 — 넘치면 모바일 크기를 한 단계 내린다.

### 화살표 — 게임처럼 큼직하게

- C4. **출발 = 누른 네모의 중앙, 끝 = 손가락/커서 위치.** 대상 네모 위에 있어도 끝은 **손가락 위치**를 따라간다
  (대상 테두리 스냅 제거). 대상 하이라이트(링)는 그대로 유지. 곡선(베지어)도 유지.
- C5. **굵고 큼직하게**: 몸통 두께 **최소 12px**, 화살촉 **길이·폭 최소 40px**. 둥근 끝.
  화살촉 **끝점이 정확히 손가락 위치**에 오게 한다(몸통이 화살촉 앞으로 삐져나오지 않게).
  SVG `<marker>` 로 이게 안 맞으면 화살촉을 곡선 끝 접선 방향으로 회전한 `<polygon>` 으로 직접 그린다.
- C6. **어떤 배경 위에서도 보이게**: 몸통·화살촉에 대비되는 외곽선(예: 흰 외곽선 위에 accent 색, 다크에선 반대 톤)
  - 그림자(`filter: drop-shadow`). 색은 `--shell-accent` 계열 변수 또는 Uno 토큰 — hex 금지.
- C7. 화살표가 네모 **위에** 그려진다(지금처럼 z-10). 드래그 중 출발 네모 글자를 가려도 된다(사용자가 중앙 출발을 원함).

### 금액 애니메이션

- C8. 잔액 표시는 부자만들기와 같은 `tools-count-number`(`app/components/tools/CountNumber.vue`, `v-model` 로 숫자 전달)를 쓴다.
  **CountNumber 수정 금지**(t1 소유). 증감 시 +/− 값이 떠오르는 효과까지 부자만들기와 똑같이 나와야 한다.
- C9. **무한대는 CountNumber 에 넘기지 않는다**(gsap 가 Infinity 를 보간하면 NaN). `Number.isFinite` 가 거짓이면 `∞` 글자.
  ∞ ↔ 유한 전환 시 컴포넌트가 바뀌는 건 괜찮다.
- C10. CountNumber 는 `v-model` 이지만 읽기만 한다 — `:model-value` 로 넘겨 prop 을 직접 변경하지 않게.
  (부자만들기는 `v-model="b.budget"` 로 쓰는데, 여기선 상태 소유자가 `useMoneyBoard` 라 단방향이 맞다.)
